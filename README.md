# markdown-lt

Markdown からリアルタイムにプレビューできるスライドアプリを目指すプロジェクトです。

詳しいアーキテクチャ・Markdown記法・CSS実装上の注意点は [DESIGN.md](DESIGN.md) を参照してください。

## 目標

- Markdown のファイルをそのままスライドとして表示する
- スライド区切りは `---` を基本にする
- ローカルで開発しやすい uv ベースの Python 環境を使う
- 変更を保存するとブラウザ側へ自動反映するライブプレビューを持つ

## 現在の設計

1. 入力
   - `slides/` 配下の `.md` ファイルを読む
   - フロントマターとスライド区切りを扱えるようにする
2. 変換
   - Markdown を HTML に変換する
   - 各スライドを `section` で分割する
3. 表示
   - FastAPI でローカルサーバーを立てる
   - ブラウザでスライドを閲覧する
4. 監視
   - 変更検知で再レンダリングする
   - 簡易なライブリロードを追加する

## 実行

```bash
uv sync --extra dev
uv run pytest -q
uv run python -m markdown_lt.server
```

または、特定のファイルを開く場合:

```bash
uv run python -m uvicorn markdown_lt.server:app --reload --port 8000
```

テーマを変える場合:

```python
from markdown_lt.server import create_app
app = create_app("slides/sample-slide/sample-slide.md", theme_name="light")
```

## タイマー機能

現在のスライドデッキには、発表用の簡易カウントダウンタイマーが組み込まれている。

- デフォルトは 5 分モード
- 3 分モードへの切替はトグルボタンで可
- 開始ボタンを押したときのみ計測開始
- 2 枚目以降に移動した時点でも、未開始なら自動で開始する
- 5 分モードでは残り 1 分以下で警告状態
- 3 分モードでは残り 30 秒以下で警告状態
- 上部のシークバーはタイマー進行と同期し、警告領域の残り時間が色で可視化される
- 残り時間が閾値を下回ると、タイマー本体と画面全体に警告演出が入る
- 時間切れでタイマーは停止し、開始ボタンを再利用可能に戻す

UI 配置は左から「開始」「モード切替」「タイマー表示」の順で、発表中に視線が自然に流れるように設計している。
